# 同校集校园互助站

原生微信小程序课程项目，当前版本 **1.0.0**。围绕大学生查资料、刷题练习和校园闲置展示，提供可交互的本机演示流程。

## 功能

- 学习资料：按学校、专业和课程筛选，搜索、收藏、评分、阅读正文，选择附件并预览、导出资料。
- 刷题练习：选择课程、作答和查看解析，保留当前设备的练习记录。
- 校园集市：二手闲置、求闲置、商品图片、成色与预算筛选、物品比较。
- 模拟拍卖：出价、截止时间、领先与被超价状态、中拍后的见面预约。
- 我的订单：见面预约和“我参与的拍卖”，查看参与竞拍及关联预约状态。
- 个人中心：主动设置头像、昵称和专业，查看发布、收藏、足迹及模拟信用记录。
- 消息与发布：模拟聊天，发布资料、闲置物品和求助。

## 数据与演示范围

当前版本没有接入共享业务后台。认证、聊天、交易和竞拍均为课程演示，没有真实支付、真实学籍核验或真人卖家即时通信；聊天使用明确标注的自动回复。

用户设置、文件、照片、发布、评价、出价、预约、订单、收藏和练习等记录保存在当前设备。不同用户、不同手机、微信开发者工具和原网页之间不会自动同步这些新增记录。清理小程序数据会删除相应的本机记录和文件。

预置资料为课堂案例，不代表学校官方资料；商品及评价包含虚构示例，照片用于同类实物参考，不代表卖家实拍。

## 在微信开发者工具中运行

1. 克隆本仓库，或在 GitHub 点击 **Code → Download ZIP** 并解压。
2. 打开微信开发者工具，选择导入项目，目录选本仓库根目录，也就是同时包含 `app.json` 与 `project.config.json` 的文件夹。
3. 团队内已有本小程序开发者权限的成员，保留 `project.config.json` 中的正式 AppID，用自己的微信登录开发者工具。AppID 本身不是 AppSecret。
4. 仓库外部的体验者若需要自行开发，请先将 AppID 替换为自己有权限使用的小程序 AppID；公开源码不授予原小程序的上传、审核或发布权限。
5. 当前版本无需 npm 安装，也不需要配置云服务或业务服务器。完成导入后点击 **编译**，再按需选择 **预览** 或真机调试。

不要在源码、Issue、提交记录或截图中加入 AppSecret、访问令牌、上传私钥及个人敏感资料。`project.private.config.json` 为本机开发者工具配置，不纳入版本控制。

## 目录

```text
app.js / app.json / app.wxss  小程序入口、页面注册与全局样式
pages/                      进入、浏览、详情、刷题、我的、发布和消息等页面
components/                 校园导航与页头等共用组件
utils/                      预置案例、筛选展示、本地存储、竞拍与预约逻辑
assets/                     吉祥物、导航图标与商品参考照片
project.config.json         微信开发者工具项目配置
使用说明.txt                版本功能、演示步骤和既有检查说明
```

更详细的开发协作步骤见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 协作与小程序版本更新

仓库协作者先拉取最新代码，再创建功能分支，修改并验证后提交 Pull Request，由团队确认后合并。

**推送到 GitHub 不会自动更新微信中的小程序。** 合并后仍需由具备权限的成员，在微信开发者工具中编译、测试并上传新版本，再到微信公众平台提交审核和发布。建议团队指定一人负责正式版本发布，避免多人上传相互覆盖。

## 素材来源与许可

公开仓库不等同于为全部内容授予统一开源许可。本仓库暂未指定整体代码许可证，不默认采用 MIT 等许可。

第三方商品参考照片分别遵循其原始许可，保留署名和来源：

- 原有照片的作者、来源与许可见 [assets/photos/SOURCE-LICENSES.md](assets/photos/SOURCE-LICENSES.md)，与当前 `photo-*.jpg` 的对应关系见 [utils/photo-map.js](utils/photo-map.js)。
- 新增 `market-*.jpg` 照片的作者、来源、许可及压缩副本信息见 [utils/market-expansion.js](utils/market-expansion.js) 中的照片元数据。

当前小程序包含为体积优化而压缩的 JPEG 副本；来源说明中提及的原始下载目录、其他尺寸或 WebP 副本不一定随本仓库提供。使用或再分发图片时，请逐项核对对应许可，不要将第三方照片标为项目自有素材或统一改授代码许可。
